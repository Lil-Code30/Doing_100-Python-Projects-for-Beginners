# 7. Alarm Clock

Design a simple alarm clock application that allows users to set alarms.

**Input values:**

User sets an alarm time.

**Output value:**

Alarm notification when the set time is reached.

> Example:

```bash
Input values:
Set alarm time: 07:30 AM

Output value:
Alarm! It's 07:30 AM. Time to wake up!
```
